# ADBrowser downloads

Windows installer, Chromium kernel packages and update metadata for ADBrowser.

[Download the latest release](https://github.com/Sucukdeluxe/adbrowser-releases/releases/latest)

Install `ADBrowser-Setup-0.1.0.exe`, then use the kernel update controls in the application to install the separate Chromium package. The release also includes checksums and update metadata.

The Windows installer is not Authenticode-signed. Kernel updates are verified using signed manifests. See the release notes for supported features and current limitations.
